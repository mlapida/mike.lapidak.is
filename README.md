# mike.lapidak.is

Personal site for Mike Lapidakis, Security & Networking SA Leader at AWS. Built with Astro 7, deployed to Cloudflare Pages.

## Stack

- **Astro 7** · static output, no adapter; unified Markdown processor preserves the rehype image plugin
- **Tailwind CSS v4** via `@tailwindcss/vite`
- **@astrojs/sitemap** · auto-generated `sitemap-index.xml` + `sitemap-0.xml`
- **@astrojs/rss** · RSS 2.0 feed at `/rss.xml`
- **Cloudflare Pages** · hosting + CI/CD (auto-deploys on push to `main`)
- **Cloudflare R2** · photo storage (`assets.lapidak.is` CDN)
- **Immich** · self-hosted photo management; albums ending in `-share` sync to the site

## Routes

| Route | Source | Notes |
|---|---|---|
| `/` | `src/pages/index.astro` | Hero, latest 5 posts with thumbnails, section cards |
| `/work/` | `src/pages/work.astro` | Career, spotlight publications, talks, skills |
| `/photography/` | `src/pages/photography.astro` | Justified-row grid + collection stacks |
| `/photography/<slug>/` | `src/pages/photography/[slug].astro` | EXIF, Leaflet GPS map, prev/next |
| `/photography/collection/<slug>/` | `src/pages/photography/collection/[slug].astro` | Per-collection grid |
| `/posts/`, `/posts/2/`, `/posts/3/` | `src/pages/posts/[...page].astro` | Writing index, paginated 10/page, year-grouped |
| `/posts/<slug>/` | `src/pages/posts/[slug].astro` | Post detail with hero image, prev/next, Article JSON-LD |
| `/posts/<slug>.md` | `src/pages/posts/[slug].md.ts` | Raw markdown source per post (noindexed) |
| `/rss.xml` | `src/pages/rss.xml.ts` | RSS 2.0 feed of all published posts with feature-image enclosures |
| `/llms.txt` | `src/pages/llms.txt.ts` | llmstxt.org-format site summary, generated from posts + work data (noindexed) |

## Photo Sync

Photos are managed in Immich and synced automatically. To sync manually:

```bash
cp .env.example .env.local   # fill in credentials
npm run sync:dry             # dry run · no writes
npm run sync                 # sync + git commit (no push)
npm run sync:build           # sync + build
```

**Album naming convention:**

| Album name | Result |
|---|---|
| `site-share` | Singles (no collection) |
| `paris-share` | Collection "Paris" (from `Title: Paris` in album description) |

Only albums ending in `-share` are synced. Images are resized to 3200px max edge and uploaded to R2. Metadata is written to `src/content/photos/*.md`.

### Required env vars

```
IMMICH_URL=https://immich.example.com
IMMICH_API_KEY=
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET_NAME=site-photos
PHOTOS_CDN_URL=https://cdn.example.com
SITE_REPO_PATH=.
```

See `.env.example` for a full template.

## Post Image Migration

Body images for imported posts are managed by an idempotent script (safe to re-run):

```bash
node scripts/migrate-post-images.mjs              # download from media.empty.coffee → public/post-images/<slug>/
node scripts/migrate-post-images.mjs --dry-run
```

Feature/hero images live at `public/post-images/<slug>/feature.<ext>` and are referenced from each post's `feature_image` frontmatter field.

## Editable Content

These files contain site content and can be updated independently of the templates:

| File | What to edit |
|------|-------------|
| `src/config/site.ts` | Name, bio, role, URL, and all social links (`socials`, `heroSocials`, `footerSocials`) |
| `src/data/work.ts` | Work experience, spotlight publications, talks, skill groups |
| `src/content/posts/*.md` | Post markdown + frontmatter (type, status, title, description, publish_date, slug, source_url, author, word_count, feature_image, tags) |
| `src/content/photos/*.md` | Photo metadata · auto-generated by the sync script, but editable manually |
| `public/profile.jpg` | Profile photo |
| `public/social-card.jpg` | Default OG/Twitter share image |
| `public/post-images/<slug>/*` | Local copies of every image referenced by a post (body + `feature.<ext>`) |

Template and layout files live in `src/layouts/`, `src/components/`, and `src/pages/`.
